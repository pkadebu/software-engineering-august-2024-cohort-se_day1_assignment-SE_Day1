#Part 1: Introduction to Software Engineering

**Explain what software engineering is and discuss its importance in the technology industry.**

Software Engineering is the application of systematic and quantifiable engineering methods, techniques and tools in the development of high quality Software within budget and time constraints. It is important because it ensures that software is developed meets the user needs and is free of bugs that potentially cause software failure.


**Identify and describe at least three key milestones in the evolution of software engineering.**
The move from structured programming with platforms like C for readable code, Object-Oriented Programming (Java) which focused on reusability, and then Agile methodologies for iterative development


**List and briefly explain the phases of the Software Development Life Cycle.**
Requirements gathering/ Planning
Design
Development/Implementation and unit testing
Integration and system testing
Installation/deployment
Maintenance/evolution


**Compare and contrast the Waterfall and Agile methodologies. Provide examples of scenarios where each would be appropriate.**
Waterfall is Sequential and each stage must be closed off before we get to the next stage
Agile is iterative development that improves on flexibility and involment of the user at each stage

Waterfall is linear with defined steps. Useful in situations where requirements don’t change much
Agile is fast, involves sprints which deliver small chunks of the software. Accommodates changing requirements of feedback is required to be integrated quickly

**Describe the roles and responsibilities of a Software Developer, a Quality Assurance Engineer, and a Project Manager in a software engineering team.**
Software Developer - writing the code for the software product
Quality Assurance Engineer - creates tests to ensure the software bugs are removed. They ensure the final product meets the user's needs.
Project Manager - They lead the planning, scoping, budgetting, setting timelines and breaking down of tasks and their allocation to team members. Then also following up on or tracking activities to reach milestones, monitoring progress to ensure the project is completed within budget and timelines and the product is of the right quality.

**Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.**
IDE is a software application that features a number of tools required for a software to be developed. It will include code editors, compilers, debuggers, and so forth. Eclipse is an example.
Version Control System - helps to track changes to the software to manage different versions. Git is an example.

**What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.**
Challenges include technology changes which can be overcome with reskilling
Software Complexity and changing requirements. This needs adoption of Agiile techniques and risk management
Gold Plaiting which adds unneccessary features through scope creep. Engineers must follow user requirements specified not to add extra features not budgetted for

**Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.**
Unit testing is done to test a single component or module before integrating it with another
Integration testing is for tsting multiple components integrated.
System testing is testing full software that has been completely integrated.
Acceptance testing ensures that a software product meets its user requirements that were specified. This signs off the deploymenyt stage even as maintenance will continue.
